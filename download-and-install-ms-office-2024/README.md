## Download and Install Microsoft Office 2024

This guide shows step-by-step instructions for downloading and installing Microsoft Office 2024.

## What is Microsoft Office 2024?

Microsoft Office 2024 is a one-time-purchase, perpetual-license productivity suite from Microsoft that provides classic desktop applications without a recurring subscription fee.

## Why use Microsoft Office 2024?

1. No subscription

2. Works offline

3. Better performance and speed

## How to download and install Microsoft Office 2024

Refer to the steps below:

## Create Folder for Installation Files

1. Create folder Office 2024 on Desktop
2. Open Browser and search for "Office Deployment Tool"
3. Go to the official Microsoft Download page: https://www.microsoft.com/en-us/download/details.aspx?id=49117
4. Download the Office Deployment Tool
5. Once downloaded, extract it into the Office 2024 folder.
6. In a new browser tab, search for "Office Customization Tool"
7. Go to the site: https://config.office.com/deploymentsettings
8. Select the architecture of the office installation
9. Select the type of office suite to install: Office LTSC Professional Plus 2024 - Volume License
10. Select version of office
11. Toggle apps on or off depending on your use
12. Select Language
13. Click Export button on the right-hand side.
14. In the Default File Format window that pops up, select "Office Open XML formats"
15. Click OK
16. Accept the License Agreement
17. Click Export for it to download.
18. Once downloaded, go the the Downloads folder and copy the Configuration.xml file and paste it into the Office 2024 folder created.
19. Move Office 2024 folder from Desktop to C/Drive
20. Run Command Prompt as Administrator.
21. Type "cd C:\Office 2024" and press Enter
22. Type "setup /configure configuration.xml" and press Enter for installation to begin.
