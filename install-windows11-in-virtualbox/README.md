## How to Install Windows 11 in VirtualBox

This guide shows step-by-step instructions for installing Windows 11 on VirtualBox.

## What is Windows 11?

Windows 11 is the current major release of Microsoft's Windows NT operating system, released on October 5, 2021, as the successor to Windows 10. It acts as the core software (or "brain") that makes a personal computer run.

## Why use Windows 11?

Users should use Windows 11 because Windows 10 reached its official end of support on October 14, 2025, meaning Windows 11 is now the primary OS receiving security updates and official support.

## How to download and install Windows 11?

Refer to the steps below:

## Download Windows 11 Disk Image (iso)

1. Go to https://www.microsoft.com/en-us/software-download/windows11

<img width="1743" height="431" alt="image" src="https://github.com/user-attachments/assets/fed71f06-f450-478a-a020-29b42552576e" />

2. Scroll down to "Download Windows 11 Disk Image (ISO) for x64 devices".

3. In the drop-down field, select Windows 11 (multi-edition ISO for x64 devices).

<img width="1278" height="605" alt="image" src="https://github.com/user-attachments/assets/4c79209c-fa03-4760-8414-e23f4982cbff" />

4. Click Confirm

5. In the "Select the Product Language" drop-down, select English (United States) or the language of your choice.

<img width="1263" height="393" alt="image" src="https://github.com/user-attachments/assets/b473bb3c-250a-46ee-923f-6818ef55afba" />

6. Click Confirm.

7. Click the "64-bit Download" button to start the download.

<img width="1200" height="288" alt="image" src="https://github.com/user-attachments/assets/96077b62-eca3-454d-991e-c689847b4f40" /> 

## Install Windows 11 on VirtualBox

1. Once the installer has been downloaded, open Oracle VirtualBox.

2. Click New.

3. In the New Virtual Machine windows, type VM Name as "Windows 11". In the ISO image drop-down, select the file location of the Windows 11 iso file.

<img width="1007" height="493" alt="image" src="https://github.com/user-attachments/assets/ce44d44d-51b0-4e86-ab36-abdc751eef62" />

4. Click Next

5. Set Password. [Note: there should not be any spaces in Host Name text box.]

<img width="1010" height="500" alt="image" src="https://github.com/user-attachments/assets/dfa741fc-7043-42ff-9dc0-88a6342acd44" />

6. Click Next

7. Specify Virtual Hardware

<img width="1008" height="496" alt="image" src="https://github.com/user-attachments/assets/ed3e1b42-c9f7-4b29-ab9c-78c439d6ce00" />

8. Click Next

9. Click Finish

10. Wait for the installation to finish.
